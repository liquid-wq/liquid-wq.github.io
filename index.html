Earn RetroAchievements on an actual NES, Mega Drive or Saturn.

No emulator, no ROM patch. The flash cartridge reads what the achievement set needs while the game runs, and your PC evaluates the achievement conditions from what it sees. Pick your console.

NES · Famicom

RAW-NES

For the EverDrive N8 PRO. The core mirrors the NES's internal RAM in real time as the CPU writes to it, so the game runs exactly as it would without it.

Sega Saturn

For the SAROO. A small addition to its firmware reads the Saturn's work RAM every single frame, and the program patches the SD card for you.

Open RAW-TURN ›

Games stay unpatched

No IPS file, no patched disc image. On the NES and the Mega Drive an FPGA core reads the console's bus, nothing is written back into the running game. The Saturn's work RAM is out of the cartridge's reach, so there the SAROO firmware reads it once per frame.

Hardcore: planned

Not active yet: RetroAchievements only counts Hardcore unlocks from approved clients. The tools are still too new to be considered and still have to pass a set of checks. Until then, unlocks are recorded as Softcore.
