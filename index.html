// EverDrive · FPGA · RetroAchievements

Earn RetroAchievements on an actual NES or Mega Drive.

No emulator, no ROM patch. A custom FPGA core inside the flash cartridge reads the console's bus while the game runs, and your PC evaluates the achievement conditions from what it sees. Pick your console.

Nintendo Entertainment System

RAW-NES

For the EverDrive N8 PRO. The core mirrors the NES's internal RAM in real time as the CPU writes to it, so the game runs exactly as it would without it.

Open RAW-NES ›

Mega Drive · Genesis

MEGA-RAW

For the Mega EverDrive. The cartridge identifies itself, so there is nothing to select — and it brings its own in-game save state menu along.

Open MEGA-RAW ›

Same idea, both consoles

Bus-snoop instead of ROM-patch. Games stay untouched: no IPS file, no injected code, nothing written back into the running game.

Hardcore, honestly

Both tools check your setup before and during a session, and only count Hardcore when the conditions are actually met.

Free to use
